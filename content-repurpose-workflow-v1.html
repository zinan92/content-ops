抖音源视频按平台分流。小红书 path 通过 Layer 1 硬 fail + Layer 2 dbs 9 维评分双层质检。图由这个 YAML 渲染生成。

自动抓取入口 Human 输入 脚本 / 确定性 本地模型 / MLX Whisper AI + system prompt Section Sink 状态与归档 最终输出
  • Source ingest 共享：4 个平台都从同一份 organized transcript + topic_plan 出发，不重复抓取。
  • 小红书是最成熟的 path：Layer 1（quality_xiaohongshu_drafts.py）做字符串硬 fail，Layer 2（dbs_xhs_review.py）用 dbs-content 风格做 9 维 LLM 评分（claude -p 子进程 + Sonnet，$0.18/篇）。
  • 公众号 API 偶发 40164（IP 未白名单），DOCX fallback 是手工兜底路径，不是常规路径。
  • 视频号 / B站 / YouTube 当前是"已迁移即归档"，内容不改写。
  • 所有平台 sink 都进 outbox dashboard；action queue 处理 Layer 1 blocked；manual review 是发布前最后人工 gate。
